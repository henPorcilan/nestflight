# Domain Shortlist

I can't check live availability or purchase a domain myself — registration requires an account and payment, which is outside what I can do on your behalf. Search doesn't return real-time WHOIS data either, so treat every name below as "worth checking," not "confirmed available." Check at Namecheap, Porkbun, or Google Domains — takes about 2 minutes for the whole list.

Not urgent for Phase 0 — the GitHub Pages URL works fine for the waitlist while you're validating. Only worth spending money on this once interviews confirm the wedge is real.

## Primary candidates (.com)

1. **nestflight.com** — closest match to the current name, worth checking first.
2. **getnestflight.com** — common fallback pattern if the bare name is taken.
3. **flynestflight.com**
4. **nestflighthq.com**

## Backup naming directions (in case Nestflight itself is taken or you want options)

5. **breaktrip.com** / **thebreaktrip.com** — leans into "school break" directly.
6. **calendartrips.com**
7. **familywindow.com** / **thefamilywindow.com** — "window" as in travel window.
8. **schoolbreakdeals.com** — very literal, good for SEO, less brandable.

## Alt-TLD fallbacks if .com is taken

- **nestflight.co** or **nestflight.io** — common startup fallback, slightly less trustworthy to non-technical parents than .com.
- **nestflight.app** — reasonable if this ends up mobile-first.
- Avoid **.io** as the primary if the audience is mainstream parents rather than a tech-savvy crowd — .com reads as more trustworthy for a consumer product.

## Recommendation

Check "nestflight.com" first since it matches the GitHub repo and existing branding. If taken, "getnestflight.com" is the cleanest fallback that keeps the name. Don't buy yet — wait until Phase 0 interviews confirm the wedge before spending on this.
