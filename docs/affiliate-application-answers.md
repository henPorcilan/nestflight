# Affiliate Application Answers — Ready to Paste

I can't create these accounts or submit these applications myself (account creation is outside what I can do on your behalf), but here are ready-to-paste answers for the standard fields each network asks for. Should take you about 5 minutes per network once you have the live site URL.

**Before applying:** make sure the live landing page (or prototype) is up at a real URL and has a visible privacy policy — most networks check for this and reject applications without one.

## 1. TravelPayouts (apply first — no minimum traffic gate)

Sign up at: https://www.travelpayouts.com/

- **Website URL:** [your live Nestflight URL]
- **Website/business description:** "Nestflight is a family trip-planning tool that matches destinations to school calendar breaks and surfaces flight/hotel deals. Pre-launch, building a waitlist and running user interviews."
- **Traffic sources:** "Pre-launch — organic/direct traffic from a waitlist landing page, personal network referrals, and parent community outreach."
